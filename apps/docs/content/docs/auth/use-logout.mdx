---
title: useLogout
description: Sign-out, with your server session cleared first.
---

`onBeforeSignOut` runs **before** Firebase clears anything. If it throws, the Firebase session is left intact and the user can retry.

```tsx
const { logout, isPending } = useLogout({ onBeforeSignOut: clearSession });

<button onClick={logout} disabled={isPending}>
  Sign out
</button>;
```

## Returns

`logout()` resolves to `{ success: true }` or a failure result. Also exposes `status`, `isPending`, `error`, and `reset`.
